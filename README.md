# Révisions de sixième

Page de révisions avec des flashcards auto-corrigées, un décompte des points et des exercices à imprimer.

- **Mathématiques** : droite, demi-droite, segment (15 cartes, 8 exercices)
- **EMC** : représenter les autres, délégués, élections, intérêt général (21 cartes, 7 exercices)

## Utilisation

Ouvrir `index.html` dans un navigateur (ordinateur, tablette ou téléphone). Aucune installation, aucun compte.
Les deux modes de révision sont le QCM corrigé immédiatement et la carte à retourner avec auto-évaluation.
Le meilleur score est gardé dans le navigateur.

Les exercices au format PDF sont aussi dans le dossier `pdf/`.

## Publication en ligne

Dans les réglages du dépôt, onglet *Pages*, choisir la branche `main` et le dossier `/ (root)`.
Pour que Pages fonctionne avec un compte gratuit, le dépôt doit être public.
